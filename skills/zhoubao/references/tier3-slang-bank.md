## 二、黑话句式骨架

> 每个骨架含 [槽位]，可从上方映射表或下方词库随机抽词填充

### S1. 抓手句
```
以 [手段/工具] 为抓手，围绕 [目标/业务线] 完成 [成果] 闭环
```
示例：以自动化测试为抓手，围绕支付核心链路完成质量保障闭环

### S2. 赋能句
```
深度赋能 [对象]，沉淀 [N] 条 [方法论/最佳实践/认知]
```
示例：深度赋能新人团队，沉淀 3 条 code review 方法论

### S3. 拉通句
```
拉通 [A方] 和 [B方] 的 [信息/数据/认知] 链路，打通 [壁垒类型] 壁垒
```
示例：拉通前端和数据组的信息链路，打通监控数据壁垒

### S4. 组合拳句
```
以 [目标] 为导向，聚焦 [领域]，形成 [手段1] + [手段2] + [手段3] 的组合拳打法
```
示例：以用户留存为导向，聚焦新手引导，形成 Push + 弹窗 + 红点 的组合拳打法

### S5. 漏斗句
```
围绕 [指标] 持续深耕，本周 [指标] 环比 [提升/优化] [X]%，[归因一句话]
```
示例：围绕注册转化率持续深耕，本周转化率环比提升 2.3%，主要得益于落地页改版

### S6. 闭环总结句
```
本周以 [核心事项] 为主线，[动词1] 了 [成果1]，[动词2] 了 [成果2]，
形成 [输入] → [过程] → [输出] 的完整闭环
```

### S7. 战略留白句（用于没做什么事的时候）
```
本周处于 [阶段名] 阶段，重点进行 [虚化动作]，为 [下一阶段] 做好 [准备类型] 储备
```
示例：本周处于方案酝酿阶段，重点进行竞品深度洞察，为 Q4 冲刺做好认知储备

### S8. 风险包装句（用于被卡住的时候）
```
[事项] 当前受 [约束因素] 制约，已通过 [应对措施] 进行 [N] 轮推动，
预计 [时间] 打通堵点，风险 [等级]
```

## 四、浓度调节规则

### 浓度 1（轻度，约 20% 黑话）
- 仅替换核心动词（做完→落地，讨论→对齐）
- 不增加修饰词
- 保持原句结构不变
- 效果：读起来像个正常但略微大厂的人

### 浓度 2（中度，约 50% 黑话）
- 替换动词 + 添加 1-2 个修饰词
- 使用 1-2 个句式骨架
- 开始出现「闭环」「链路」「赋能」
- 效果：读起来像刚从某厂跳槽出来的人

### 浓度 3（巅峰，约 90% 黑话）
- 全面替换 + 大量修饰词堆叠
- 每条至少使用一个句式骨架
- 大量使用「以 X 为 Y」「围绕 X 深耕 Y」结构
- 必须出现：闭环、抓手、赋能、沉淀、方法论 至少各一次
- 效果：你仔细看每句好像都有道理，但合在一起完全不知道他干了什么
