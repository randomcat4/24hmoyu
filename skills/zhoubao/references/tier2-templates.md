# Tier 2 · 老油条万能句式库

> 每条标注适用岗位：🌐通用 💻技术 📦产品 📊运营 💰销售

---

## A. 本周完成类

### A1. 功能上线型
- 🌐 完成 [功能/模块名] 的开发与上线，已投入使用
- 💻 [功能名] 上线，覆盖 [N] 个 [用户/场景/接口]，运行稳定
- 💻 完成 [功能名] 从开发到灰度到全量的全流程，当前 [指标] 为 [值]
- 📦 [功能名] 上线并通知相关方，首批 [N] 位用户已开始使用
- 📊 [活动/功能] 上线，截至周五已产出 [N] [单位]

### A2. 问题修复型
- 💻 排查并修复 [系统/模块] 的 [问题简述]，[指标] 由 [旧值] 恢复至 [新值]
- 💻 定位 [问题根因简述]，修复后 [受影响范围] 恢复正常
- 🌐 处理 [N] 个 [工单/反馈/异常]，均已在 [时间范围] 内关闭
- 💻 修复 [组件名] 在 [场景] 下的 [异常表现]，补充 [N] 条相关测试

### A3. 会议协作型
- 🌐 与 [部门/人名] 完成 [主题] 的讨论，明确 [结论/分工/排期]
- 🌐 组织 [N] 次 [主题] 会议，输出 [会议纪要/结论文档/排期表]
- 📦 与 [角色] 完成 [主题] 的方案评审，确定 [方向/方案]
- 🌐 参与 [会议名称]，认领 [N] 项后续待办

### A4. 文档输出型
- 🌐 完成 [文档名] 的撰写，已提交 [评审/归档/相关方]
- 💻 更新 [系统/模块] 的技术文档，覆盖 [N] 个核心流程
- 📦 输出 [PRD/设计稿/方案] v[N]，进入 [评审/开发] 阶段
- 🌐 整理 [主题] 的 [复盘报告/分析文档]，共 [N] 页/[N] 字

### A5. 数据分析型
- 📊 完成 [数据主题] 分析，发现 [N] 个关键发现，已同步给 [相关方]
- 📊 [指标名] 本周 [上升/下降] [X]%，主要原因为 [简述]
- 📊 产出 [报表/看板/数据周报]，覆盖 [范围/维度]
- 💰 本周 [线索/商机/签约] [N] 个，较上周 [+/-] [N] 个

### A6. 日常运维 / 杂项型
- 💻 完成 [N] 次 code review，重点关注 [方向/模块]
- 🌐 处理 [N] 个跨部门需求，涉及 [部门列表]
- 💻 升级 [依赖/工具/环境] 至 [版本号]，兼容性验证通过
- 🌐 协助 [同事/新人] 完成 [事项]

### A7. 调研/学习型
- 🌐 完成 [主题] 的调研，输出 [对比文档/选型建议/调研报告]
- 💻 调研 [N] 个 [方案/工具/框架]，推荐采用 [选中方案]，原因为 [一句话]
- 🌐 参加 [培训/分享会]，整理 [N] 条可落地的改进点

---

## B. 进行中 / 风险类

### B1. 正常推进型
- 🌐 [项目/任务] 按计划推进中，当前进度 [X]%，预计 [日期] 完成
- 🌐 [项目名] 本周完成 [阶段]，下周进入 [下一阶段]
- 💻 [模块名] 开发中，核心逻辑已完成，剩余 [联调/测试/文档]

### B2. 有风险型
- 🌐 [项目名] 进度略有延迟，原因为 [简述]，预计推迟 [N] 天
- 🌐 [项目名] 目前卡在 [环节]，需要 [谁] 协助 [什么]
- 🌐 [事项] 存在 [风险简述]，已 [采取措施/上报/制定备选方案]

### B3. 外部依赖型
- 🌐 [事项] 等待 [外部方/上游] 提供 [资源/接口/确认]，已跟进 [N] 次
- 🌐 [事项] 依赖 [前置条件]，预计 [日期] 就绪后启动

---

## C. 下周计划类

### C1. 延续型
- 🌐 继续推进 [项目名]，重点完成 [具体子项]
- 🌐 [项目名] 进入 [阶段名]，计划 [日期] 前完成
- 💻 完成 [模块] 的 [联调/测试/上线]

### C2. 新启动型
- 🌐 启动 [项目/任务]
- 📦 开始 [项目名] 的 [需求评审/方案设计/排期]
- 📊 开展 [数据主题] 的 [分析/复盘]

### C3. 收尾型
- 🌐 完成 [项目名] 的 [验收/上线/交付/归档]
- 🌐 [项目名] 收尾，处理遗留问题并输出 [复盘文档/总结]

### C4. 持续型
- 🌐 跟进 [事项]，确保 [目标/时间节点]
- 🌐 持续关注 [指标/系统] 运行情况

---

## D. 万能开头（本周小结，1-2 句话）

- 🌐 本周主要围绕 [X] 和 [Y] 推进，整体进度符合预期
- 🌐 本周重点完成 [X]，同时推进 [Y] 和 [Z]
- 🌐 本周核心工作为 [X]，另处理 [N] 项日常事务
- 🌐 [项目名] 本周达成 [里程碑/关键节点]，其余工作正常推进
- ⚠️ 本周 [项目名] 遇到 [卡点简述]，其余工作正常推进

## E. 万能收尾（风险提示，可选）

- 🌐 当前主要风险：[X]，已 [应对措施]
- 🌐 需要支持：[具体事项]，希望 [谁] 协助 [什么]
- 🌐 无特殊风险，按计划推进

---

## 使用说明

1. Skill 根据用户输入的工作内容，自动匹配最相近的句式类别
2. 将用户原始内容填入 [槽位]
3. 选取「万能开头」中的一条作为小结
4. 组装为标准周报结构输出
5. 对于匹配不上任何模板的条目，用 Tier 1 规范直接改写（不强行套模板）
